Lập trình mạng với Java - Các khái niệm cơ bản

Học các khái niệm cơ bản về lập trình mạng trong Java bao gồm Socket, TCP/IP và các giao thức mạng.
15 tháng 12, 2024 · Lập trình viên

Giới thiệu#

Lập trình mạng là một kỹ năng quan trọng trong phát triển ứng dụng hiện đại. Java cung cấp một thư viện mạnh mẽ cho phép chúng ta xây dựng các ứng dụng mạng phức tạp.

Các khái niệm cơ bản#

Socket là gì?#

Socket là một điểm cuối của kết nối mạng. Nó đại diện cho một đầu cuối của một kết nối giữa hai máy tính trên một mạng.

import java.io.*;
import java.net.*;

public class SimpleSocketExample {
    public static void main(String[] args) throws IOException {
        Socket socket = new Socket("localhost", 8080);
        PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
        BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream())
        );
        
        out.println("Hello Server!");
        String response = in.readLine();
        System.out.println("Response: " + response);
        
        socket.close();
    }
}

TCP/IP Protocol#

TCP/IP là nền tảng của Internet. Nó bao gồm:

  • TCP (Transmission Control Protocol): Đảm bảo truyền dữ liệu tin cậy
  • IP (Internet Protocol): Định tuyến dữ liệu giữa các máy tính
