Khám phá UDP Protocol trong Java

Tìm hiểu về UDP (User Datagram Protocol) và cách sử dụng nó trong Java.
13 tháng 12, 2024 · Lập trình viên

Giới thiệu UDP#

UDP là một giao thức không tin cậy nhưng nhanh chóng, không yêu cầu thiết lập kết nối. Nó thích hợp cho các ứng dụng yêu cầu tốc độ hơn độ chính xác.

UDP vs TCP#

Tính chất TCP UDP
Tin cậy Có Không
Thứ tự dữ liệu Bảo đảm Không bảo đảm
Tốc độ Chậm hơn Nhanh hơn
Kết nối Yêu cầu Không yêu cầu

Ví dụ UDP Sender#

import java.io.*;
import java.net.*;

public class UDPSender {
    public static void main(String[] args) throws IOException {
        DatagramSocket socket = new DatagramSocket();
        InetAddress address = InetAddress.getByName("localhost");
        int port = 8888;
        
        String message = "Hello UDP Server!";
        byte[] data = message.getBytes();
        
        DatagramPacket packet = new DatagramPacket(
            data, data.length, address, port
        );
        
        socket.send(packet);
        System.out.println("Gửi: " + message);
        
        socket.close();
    }
}

Ví dụ UDP Receiver#

import java.io.*;
import java.net.*;

public class UDPReceiver {
    public static void main(String[] args) throws IOException {
        DatagramSocket socket = new DatagramSocket(8888);
        byte[] receiveData = new byte[1024];
        
        System.out.println("Server UDP lắng nghe trên cổng 8888");
        
        while (true) {
            DatagramPacket packet = new DatagramPacket(
                receiveData, receiveData.length
            );
            
            socket.receive(packet);
            String message = new String(packet.getData(), 0, packet.getLength());
            System.out.println("Nhận được: " + message);
            System.out.println("Từ: " + packet.getAddress().getHostAddress());
        }
    }
}

Ứng dụng của UDP#

  1. Video/Audio streaming: Không cần độ tin cậy tuyệt đối
  2. Online games: Cần tốc độ thấp độ trễ
  3. DNS queries: Mỏng nhẹ và nhanh
  4. IoT applications: Tiết kiệm tài nguyên

Kết luận#

UDP là lựa chọn phù hợp khi bạn cần tốc độ cao và có thể chấp nhận mất một số dữ liệu.
