Căn bản về JavaScript Async/Await cho lập trình mạng

Giới thiệu Async/Await Async/Await là cách hiện đại để xử lý các hoạt động bất đồng bộ trong JavaScript, đặc biệt hữu ích cho lập trình mạng. Callbacks vs Promises vs Async/Await Callback Hell function fetchData(url, callback) { fetch(url, (error, data) => { if (error) { fetch(url + '/retry', (retryError, retryData) => { if (retryError) callback(retryError); else callback(null, retryData); }); } else { callback(null, data); } }); } Với Async/Await async function fetchDataWithRetry(url) { try { const response = await fetch(url); return await response.json(); } catch (error) { console.log('Retry fetch...'); const retryResponse = await fetch(url + '/retry'); return await retryResponse.json(); } } Ví dụ thực tế async function getNetworkData() { try { // Gọi API const response = await fetch('https://api.example.com/data'); if (!response.ok) { throw new Error(`HTTP error! status: ${response.status}`); } const data = await response.json(); console.log('Dữ liệu:', data); return data; } catch (error) { console.error('Lỗi:', error); } } Xử lý nhiều yêu cầu // Serial - Lần lượt async function fetchSerially() { const data1 = await fetch('/api/data1').then(r => r.json()); const data2 = await fetch('/api/data2').then(r => r.json()); return [data1, data2]; } // Parallel - Song song async function fetchParallel() { const [response1, response2] = await Promise.all([ fetch('/api/data1'), fetch('/api/data2') ]); const [data1, data2] = await Promise.all([ response1.json(), response2.json() ]); return [data1, data2]; } Timeout xử lý function withTimeout(promise, ms) { return Promise.race([ promise, new Promise((_, reject) => setTimeout(() => reject(new Error('Timeout')), ms) ) ]); } async function fetchWithTimeout(url, timeoutMs) { try { const response = await withTimeout(fetch(url), timeoutMs); return await response.json(); } catch (error) { console.error('Lỗi:', error); } } Kết luận Async/Await làm cho mã bất đồng bộ dễ đọc và dễ bảo trì hơn, rất quan trọng cho lập trình mạng hiệu quả.
